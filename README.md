# EMCURE Design Studio

A faculty tool for designing an entrepreneurially minded course-based undergraduate research experience (EMCURE).

This is a **draft**. There is no AI API and no backend database. Designs save in the browser.

## Run

```bash
cd app
npm install
npm run dev
```

See `app/README.md` for tests, export, and usage.
